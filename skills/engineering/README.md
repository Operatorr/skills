# Engineering Skills

- **[code-review](./code-review/SKILL.md)** — deep, context-aware reviews for GitHub PRs and local branch changes, with severity-ranked findings and handoff prompts.
- **[git-commit](./git-commit/SKILL.md)** — stage all changes and create a git commit with an auto-generated, convention-matched message.
- **[git-pr](./git-pr/SKILL.md)** — branch off master/develop when needed, commit all changes, push, and open a PR automatically.
