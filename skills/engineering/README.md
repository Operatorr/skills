# Engineering Skills

- **[visual-review](./visual-review/SKILL.md)** — inspect a PR's running UI through computer use for visual defects, responsive layout issues, and actionable UX improvements, with screenshot evidence.
- **[code-review](./code-review/SKILL.md)** — bounded bug hunting with independent Standards and Spec reviewers, concrete behavior traces, and verified Critical/High/Medium/Low findings; no per-file fan-out or scanner battery.
- **[deep-review](./deep-review/SKILL.md)** — maximally thorough, CodeRabbit-style review: per-file sub-agent fan-out, independent Standards and Spec reviewers, full linter/SAST/secret-scanner battery, and every substantive issue from Critical to Low, without nitpicks (the exhaustive counterpart to code-review).
- **[git-commit](./git-commit/SKILL.md)** — stage all changes and create a git commit with an auto-generated, convention-matched message.
- **[git-pr](./git-pr/SKILL.md)** — branch off master/develop when needed, commit the work, push, and open a PR automatically, with a summary-first body, verification evidence, and before/after screenshots for UI changes.
